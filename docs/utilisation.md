# Guide d’utilisation de PerformCV

## 1. Créer un compte et se connecter

Depuis l’accueil, choisir **Commencer**, renseigner le prénom, le nom, l’adresse
email et le mot de passe demandé, puis valider **Créer mon compte**. Se connecter
ensuite avec cette adresse et ce mot de passe. L’espace personnel affiche les
profils du compte.

Dans **Mon compte**, modifier le nom, le prénom et le téléphone. Ces coordonnées,
ainsi que l’email du compte, peuvent apparaître sur les CV et les profils publics.
Le changement de mot de passe dispose de son propre formulaire. Aucune procédure
de récupération par email n’est actuellement proposée dans les contrôleurs.

## 2. Renseigner son profil professionnel

Dans **Mon espace**, choisir **Nouveau profil** et renseigner :

- un titre professionnel et une présentation ;
- la localisation et, si souhaité, les liens vers le site, LinkedIn et GitHub ;
- la visibilité du profil, privée par défaut.

Après enregistrement, ajouter les rubriques utiles depuis la page du profil :
expériences, formations, certifications, projets, langues et compétences.
Les boutons **Ajouter**, **Modifier** et **Supprimer** permettent de gérer chaque
entrée. Les dates renseignées doivent être cohérentes ; pour un poste actuel,
utiliser le réglage correspondant. Aucun dépôt de photo ou de fichier justificatif
n’est proposé dans ces formulaires.

Un compte peut avoir plusieurs profils. Utiliser par exemple un profil par
orientation professionnelle. La limite technique est de 100 entrées par rubrique.

## 3. Composer un CV et choisir son modèle

Depuis un profil, choisir **Créer un CV**. L’éditeur propose huit modèles,
la palette, la typographie et les rubriques à rendre visibles.

| Modèles | Prix |
|---|---:|
| Classique ATS, Moderne | Gratuit |
| Executive, Tech Developer, Créatif, Élégance, Étudiant, Timeline | 3,90 € chacun |

Cliquer sur une carte pour actualiser l’aperçu avec les informations du profil.
Une modification de palette, de typographie ou de rubriques actualise également
l’aperçu lorsque JavaScript est disponible. Le bouton **Prévisualiser** reste
utilisable sans JavaScript. Un aperçu ne modifie pas le CV enregistré.

Choisir **Enregistrer le CV** pour appliquer les réglages. Revenir ensuite par
**Personnaliser** pour les modifier. Il est possible de créer plusieurs CV à
partir d’un même profil, jusqu’à 50 CV par profil.

Les modèles orientés ATS privilégient une lecture linéaire. Les compositions
graphiques, notamment les colonnes et repères décoratifs, peuvent être moins bien
interprétées par certains logiciels. Aucune compatibilité universelle n’est garantie.

Les CV utilisent les données actuelles du profil : modifier une expérience ou
une coordonnée peut modifier les CV existants associés. Ce ne sont pas des copies
figées de votre parcours.

## 4. Acheter un modèle

Tous les modèles peuvent être prévisualisés gratuitement. Pour un nouveau CV,
enregistrer d’abord un modèle gratuit. Choisir ensuite un modèle payant dans
l’éditeur et utiliser **Acheter [nom du modèle]** lorsque les achats sont activés.

Le paiement se déroule sur Stripe Checkout. Après le retour sur PerformCV,
attendre la confirmation puis actualiser l’éditeur si nécessaire. Le retour seul
ne débloque pas le modèle : PerformCV attend la confirmation du paiement par
Stripe. Un modèle confirmé apparaît comme **Déjà acheté** et peut être utilisé
sur les CV du même compte, sans abonnement ni nouvel achat par CV.

Après confirmation, sélectionner le modèle et enregistrer le CV. L’achat seul
ne change pas automatiquement la présentation du CV.

Si **Achat bientôt disponible** est affiché, les paiements ne sont pas encore
configurés sur cet environnement. Un paiement annulé n’applique pas le modèle.
En cas de confirmation durablement absente ou de demande de remboursement,
contacter l’éditeur via les coordonnées des mentions légales ; aucun traitement
automatique des remboursements n’est proposé dans l’application.

## 5. Imprimer ou enregistrer en PDF

Ouvrir le CV enregistré et choisir **Imprimer / PDF (ATS)**. Dans la fenêtre du
navigateur, sélectionner **Enregistrer au format PDF**, un format A4 et désactiver
les en-têtes et pieds de page du navigateur.

Le rendu d’impression utilise une présentation simplifiée sur une colonne,
y compris pour un modèle graphique à l’écran. Le PDF est créé par le navigateur.
Vérifier le nombre de pages, les liens et la possibilité de sélectionner le texte
dans le bon ordre avant de le transmettre. Les rubriques masquées sont exclues
du contenu rendu. L’aperçu de l’éditeur n’est pas le parcours d’impression :
enregistrer d’abord un modèle gratuit ou acheté, puis ouvrir le CV.

## 6. Partager un CV

Depuis le CV enregistré, choisir **Partager** ou **Créer un lien**. Renseigner les
réglages souhaités : activation du lien, éventuel mot de passe et expiration.
Copier ensuite l’adresse affichée et la transmettre au destinataire. La limite
technique est de 20 liens par CV.

| Réglage | Effet |
|---|---|
| Profil privé | Le profil n’est pas accessible par son adresse publique ; un lien de CV actif peut néanmoins fonctionner. |
| Profil public | Le profil et ses coordonnées deviennent accessibles par son adresse et peuvent être référencés par les moteurs. |
| Lien actif | Autorise l’accès au CV selon sa protection et sa date d’expiration. |
| Mot de passe | Demande un déverrouillage au visiteur ; celui-ci dure au maximum une heure et l’état du lien est revérifié. |
| Lien expiré, désactivé ou révoqué | Empêche les accès futurs par ce lien. |

Un lien de partage ne rend pas le profil public. **Révoquer le lien** supprime le
lien et les statistiques associées. Les copies déjà enregistrées par des
destinataires ne sont pas supprimées. Ne pas publier le lien ni son mot de passe
dans des espaces où leur accès n’est pas souhaité.

## 7. Comprendre les consultations et les cookies

Le compteur anonyme de chaque lien enregistre chaque affichage réussi, y compris
les rechargements, sans demander de consentement. Il ne stocke ni IP, ni
user-agent, ni référent, ni identifiant du visiteur et n’utilise aucun cookie de
mesure ou repère de comptage en session. Ce n’est pas un nombre de visiteurs uniques.
Les anciennes consultations peuvent être supprimées par la purge de conservation.

Le lien **Cookies et traceurs** décrit les cookies nécessaires au service.
Le marketing et les balises Google restent désactivés dans le code actuel.

## 8. Supprimer ses données

La suppression d’une rubrique retire l’entrée du profil et des CV qui la lisent.
La suppression d’un CV retire ses liens et leurs consultations. La suppression
d’un profil retire ses rubriques, ses CV, ses liens et les consultations liées.

Dans **Mon compte**, **Supprimer mon compte** ouvre un formulaire de confirmation.
Cette suppression retire les profils, CV, liens, consultations et achats de la
base applicative et met fin à la session. Les données détenues par Stripe,
les éventuelles archives comptables et les copies téléchargées par d’autres
personnes suivent un traitement distinct. Consulter la politique de confidentialité
pour les droits et les coordonnées de contact.

## Difficultés courantes

| Message ou problème | Action |
|---|---|
| Formulaire expiré | Recharger la page puis recommencer ; ne pas réutiliser une ancienne page de formulaire. |
| Aperçu indisponible | Vérifier les champs et utiliser Prévisualiser. Vérifier la connexion si le problème persiste. |
| Enregistrement indisponible sur un modèle payant | Vérifier que l’achat est confirmé sur le compte connecté ou sélectionner un modèle gratuit. |
| Lien introuvable | Vérifier l’adresse, l’expiration et l’activation auprès du propriétaire. |
| Compteur nul malgré un partage | Utiliser le lien de partage actif : les aperçus privés et les liens inaccessibles ne sont pas comptés. |
| PDF différent de l’aperçu | Le rendu PDF est volontairement linéaire pour faciliter la lecture par les ATS. |
| Connexion temporairement bloquée | Attendre la fin de la limitation des tentatives ; éviter les essais répétés. |

Pour les opérations techniques, consulter la [procédure de production](mise-en-production.md).

## Publier un CV dans l’annuaire

Dans la gestion d’un CV, la section **Annuaire public** permet de publier volontairement le CV et d’autoriser son référencement. Cette option est désactivée par défaut. Vos nom, prénom et titre doivent être renseignés, et le CV doit disposer d’un lien actif sans mot de passe et non expiré. Le contenu visible du CV et vos coordonnées seront publics. Le bouton **Retirer de l’annuaire** interrompt la publication ; les moteurs peuvent conserver temporairement leurs résultats. Voir [le fonctionnement de l’annuaire et son classement](annuaire-cv.md).
